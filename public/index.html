Setup needed

The server is missing its Google credentials. Add them to the .env file in the project folder, then restart the server.

  1. Google Cloud Console → your project → Credentials (or Google Auth Platform → Clients) → your Web application client.
  2. Under Authorized redirect URIs, add http://localhost:5173/auth/callback.
  3. Copy the Client ID and Client secret into .env.
  4. Restart: npm start

Full steps are in README.md.
